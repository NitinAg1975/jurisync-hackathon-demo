# JURISYNC AI Dashboard

This is the frontend prototype for the JURISYNC legal integrity dashboard.

## Installation Instructions

Because this is a pure frontend prototype, no complex installation or backend server is required to run it.

1. **Download the code:** Clone this repository or download the ZIP file and extract it.
2. **Open the file:** Locate the `index.html` file in the main folder.
3. **Run the app:** Double-click `index.html` to open it directly in any modern web browser (Chrome, Edge, Safari, Firefox). 

*Note: You do not need to run `npm install` or start a local server.*
